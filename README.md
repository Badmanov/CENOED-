# 🦖 ЦЕНОЕД

ЦЕНОЕД — умный Telegram-сервис для поиска, сравнения и отслеживания цен.

## Возможности

- 🔎 Поиск товаров
- 📸 Поиск товара по фото
- 🔗 Проверка цены по ссылке
- 💰 Сравнение цен
- 🔥 Поиск акций
- 📊 История изменения цены
- 🔔 Уведомления о снижении цены
- 🛒 Персональные отслеживания

Цель проекта — помочь пользователю покупать товары по действительно выгодной цене.
